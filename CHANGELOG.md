# Changelog

**English** · [Español](CHANGELOG.es.md)

Notable changes to the KiBoard Android application. The Windows host maintains its own changelog.

## 2.0.2 (2026-09-04) — protocol `v0.5.0`

### Changed

- Buttons have stronger depth, contrast, and touch feedback without sacrificing readability in
  portrait, landscape, or tablet layouts.
- Google Play documentation and release notes now reflect the joint 2.0.2 release.

### Added

- Play Store icon, feature graphic, and four screenshots each for portrait phone, landscape phone,
  and tablet.
- Bilingual store-listing, distribution, and Data safety guidance.

## 2.0.1 (2026-09-03) — protocol `v0.5.0`

### Changed

- Refreshed automatic decks, a recent-app Launcher, and high-resolution icons.
- Manual mode is reserved for custom decks and offers fewer redundant actions.

### Fixed

- Selecting or launching an application from Launcher returns to its automatic deck.
- Connection, navigation, and page-transition improvements.

### Added

- Optional anonymous interaction analytics, configurable from the Windows host.
